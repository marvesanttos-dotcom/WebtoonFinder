# Webtoon Finder

Aplicativo Android para pesquisar webtoons em português e abrir páginas de leitura dentro do próprio app.

## Recursos
- Busca com termos em português para localizar webtoons e páginas de leitura gratuita.
- Navegação de páginas HTTPS dentro do aplicativo.
- Leitor com zoom e carregamento das imagens na qualidade disponibilizada pelo site de origem.
- Modos de visualização: rolagem vertical, página por página, duas páginas lado a lado e leitura horizontal (ajustes de layout aplicados quando o site permite).
- Favoritos e histórico locais.
- Modo de tela cheia.

## Privacidade e conteúdo
O app não hospeda capítulos nem remove anúncios, paywalls ou restrições dos sites. A disponibilidade, idioma e qualidade dependem da fonte aberta. A pesquisa usa termos em português, mas resultados externos podem conter páginas em outros idiomas.

## Compilar
Abra o projeto no Android Studio com JDK 17 e compile o módulo `:app`, ou use o workflow **Gerar APK Android** em GitHub Actions. O APK de depuração é publicado como artefato da execução.

## Requisitos
Android 6.0 (API 23) ou superior.
